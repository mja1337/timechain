# Custody equipment artwork

Nineteen distinct SVG illustrations use the mining hardware's steel, circuit-green and amber palette and its 64 × 46 drawing space:

- `basic-pc.svg`: one complete computer SKU
- `mini-pc.svg`: small-form-factor computer
- `pi-kit.svg`: Raspberry Pi kit and storage
- `hardware-wallet.svg`: generic dedicated signer
- `qr-signer.svg`: generic camera/display signer
- `microsd.svg`: boot or transfer media
- `usb-drive.svg`: transfer media
- `paper-backup.svg`: paper recovery material
- `steel-backup.svg`: steel recovery material
- `bitcoin-node.svg`: Bitcoin node service station
- `lightning-node.svg`: Lightning upgrade service station
- Eight separate catalogue illustrations: `trezorone.svg`, `nanos.svg`, `coldcard.svg`, `coldcardmk4.svg`, `nanox.svg`, `bitbox02.svg`, `jade.svg` and `passport.svg`. Each has a distinct enclosure, display and detail layout; these are illustrative rather than product drawings.

Use the standalone files as image sources. `equipment-detailed.svg` contains the detailed symbols, with separate gradient identifiers for each asset. `equipment.svg` retains the original nine drawings as the baseline for the detail comparison. Each asset has its own drawing; no hardware type or node service borrows another asset's icon.

`detail-counts.json` records the number of path, rectangle, circle, line, ellipse, polygon and polyline elements. Each of the original nine assets exceeds 7.5 times its baseline count. The two node service illustrations are new. These illustrations are generic and do not establish hardware specifications, historical availability or security guarantees.

The live custody workshop uses the standalone illustrations on its floor and catalogue rows. Setup, purchasing, delivery and storage controls connect to the game's engine. The inline review concept remains available for editorial comparison.
